

## 设计师执行规范 · V1.1

本节是后续产品、界面、宣传物料和商品应用的设计依据。图形文件包仍为 V1；本次更新补齐交接规范并纠正文化示意图，没有自动批准新的 Logo 造型或品牌配色。

### 2. 品牌气质与业务表达

品牌应给人温和、可靠、清楚、有秩序的感觉。业务涉及软件与信息服务、工程配套、生态技术、设备物资及运营生活服务，视觉可以支持多类产品，不把公司限定为单一环保、建筑或政务软件品牌。

版式以清晰层级、充分留白和节制装饰为基础。产品功能表达具体说明用途与价值，不虚构已交付案例、获奖、资质、合作机构或行业领先结论。

### 3. C 标志的结构与文化寓意

主标把“礼”的字形关系与开放的近方形轮廓结合。保留左部笔画节奏、内部曲折、右下延伸端和开放缺口；这几部分共同形成识别。

| 理念 | 在标志中实际观察的位置 | 设计含义 |
| --- | --- | --- |
| 善心 | 中上部由笔画围合形成的白色空间 | 用留白与包容感表达善意 |
| 善念 | 左部横画转向斜画的转折关系 | 表达思考、理解和连接 |
| 善行 | 右下方横画的延伸与开放端 | 表达将善意落实为行动 |

纠正说明：原文化概念图①单独画出的 U 形，是抽象示意，主标中不存在原样的独立 U 形笔画。本节及新版标注图将“善心”对应到实际白色空间，不再作错误的笔画拆分。三个理念属于设计寓意，不代表 Logo 由三根笔画构成。

### 4. 母版与参考资料的优先级

执行优先级：01-master 中的 SVG 图形路径 → 固定外观的 PNG → 本规范 → 应用效果图与早期概念稿。

- 独立印记以 symbol-black.svg / symbol-white.svg 为准；两个版本只变颜色，不改形状。
- 当前独立母版画板为 512×512；内部图形按同一坐标和比例输出。画板边界不等于可见图形边界，也不等于安全留白。
- 复制完整路径组进行等比缩放，不凭预览图描摹，不按“标准圆角”重画局部，不用相似字体“礼”字替换印记。
- 黑白横版画板为 780×208，竖版画板为 564×512。先使用完整组合，不单独拉伸图形、汉字或英文。
- 应用效果图中的透视、阴影、材质和灯光只表达使用场景，不是 Logo 固有样式。

### 5. 标志组合与选择

| 组合 | 使用场景 | 保留内容 |
| --- | --- | --- |
| 独立印记 | favicon、App、小头像、小尺寸角标 | 只保留图形 |
| 横版组合 | 网站页头、软件登录页、宣传页、包装侧面 | 印记＋礼林生态＋LILIN ECO |
| 竖版组合 | 方形标签、吊牌、正面包装、竖向宣传位 | 印记在上，中文和英文在下 |
| 公司全称抬头 | 公司公告、正式公司材料 | 印记＋完整公司名称；优先保证全称可读 |
| 文化辅助组合 | 广告展板、品牌介绍、商品辅助信息面 | 标志与“善心 · 善念 · 善行”分层排版 |

当横版空间不足时，切换独立印记并在界面中正常显示产品名称；不要把完整组合压成窄条，也不要把英文缩成难以辨认的装饰线。新增纯中文组合、产品专属图标等应单独提交审稿，不能各自改造企业标志。

### 6. 安全留白、最小尺寸与光学校正

定义 H 为可见印记的实际高度，u＝H÷5。外部文字、图案、裁切边、装订位置与标志可见边界之间，建议至少保留 1u；组合标志按整个组合的外边界留白，u 仍取其中印记高度。

PNG/SVG 自带的透明边距不能直接当成已满足净空；排版时仍需检查。应用图标的整面背景可以延伸到画板边缘，但印记需处于安全区域。

以下为本交接版建议起点，不是已经完成所有材质打样后的硬性下限：

| 用法 | 建议尺寸起点 | 缩小时处理 |
| --- | --- | --- |
| 普通数字界面独立印记 | 可见高度 24 CSS px 起 | 检查开放缺口与内部留白 |
| 浏览器 favicon | 使用专用 16/32/48 导出 | 16 px 为特殊小图，按实际浏览器复核 |
| 带英文的横版组合 | 完整画板显示宽约 280 CSS px 起 | 英文不清楚时换独立印记 |
| 带英文的竖版组合 | 完整画板显示宽约 220 CSS px 起 | 同上 |
| 普通平面印刷独立印记 | 可见高度约 8 mm 起 | 以纸张与印刷清晰度打样确认 |
| 带英文组合印刷 | 横版约 60 mm 宽、竖版约 50 mm 宽起 | 以最小文字实际可读为准 |

视觉居中可对整体做微量位置调整，不能改变局部比例。刺绣、雕刻、烫印、丝印等工艺应向供应商确认最细线与最小间隙；如需简化，另建“工艺适配版”并送审，不覆盖通用母版。

### 7. 色彩与背景

当前 Logo 母版仅确定黑白表达：黑色 #000000（RGB 0/0/0），反白 #FFFFFF（RGB 255/255/255）。普通单黑印刷可从 K100 单色稿开始，由印厂按实际工艺确认；不直接把屏幕 RGB 数值当作已审定的 CMYK 或专色。

现官网界面配色可供设计师理解既有气质，不能据此改变本轮黑白 Logo：

| 角色 | 官网当前值 | 用法参考 |
| --- | --- | --- |
| 品牌界面绿 | #36593E | 主按钮、重点链接 |
| 深绿 | #26432D | 重点及交互深色态 |
| 暖米白 | #F8F7F3 | 页面底色 |
| 浅暖白 | #FDFCF9 | 内容底色 |
| 正文墨色 | #292F29 | 主要文字 |
| 辅助文字 | #6C7068 | 使用前检查实际背景对比度 |
| 分隔线 | #DDDFD5 | 边界与分组 |

浅色纯净背景优先黑标，深色纯净背景使用反白；照片上优先选择安静区域或独立底色容器。不要用半透明弱化主标、把照片纹理穿入字形，或自行添加渐变、描边、投影和发光。

正文、按钮、状态文字应单独检查可读性；可参考 WCAG 普通文字 4.5:1、大字 3:1 的对比度要求。装饰背景字不能承载唯一的关键信息。Logo 自身与界面正文不混为一类检查。

### 8. 字体、字距与中文排版

现有组合母版中的中文为 Microsoft YaHei 字体栈、600 字重；英文为同一字体栈、400 字重。横版设计坐标中中文字号 64、英文 29、英文字距 6；竖版中文 56、英文 24、英文字距 5。这些是对应 SVG 画板内的设计单位，不是网页应直接使用的 CSS 字号。

Microsoft YaHei、Noto Sans SC、Arial 和系统回退字体可能产生不同字形与宽度，现有文字仍可编辑，并未转曲。后续正式字标需要锁定字体来源、字体版本、字重、字距和外观；正式交付同时提供文字转曲母版与可编辑文本稿，并附字体使用依据，不将字体文件随意打包分发。

官网目前正文采用系统无衬线字体栈，标题及文化背景采用宋体／衬线字体栈。其他产品可沿用“正文清晰、标题有人文感”的层级，但不能让品牌字标随产品主题字体变化。

中文全称应保持完整或在完整词组之间合理换行，避免把“有限责任公司”拆成难以识别的碎行。品牌简称固定为“礼林生态”；英文固定为“LILIN ECO”，不自行改成 LiLin、Lilin Technology 等名称。

### 9. “善心、善念、善行”的辅助使用

顺序固定为善心、善念、善行。完整句式采用“善心、善念、善行”；独立排版可用“善心 · 善念 · 善行”。三词字号、字重和间距应一致，作为次级信息与主标分开。

小尺寸图标里不塞入三词。网站大背景可延续目前文化字约 4.5% 的低透明度效果，但仅作为装饰；应同时考虑底图与正文对比，必要时移开，不机械套透明度。不要把三词缩成难读的水印覆盖内容，也不把理念解释为公司只有三项业务。

### 10. 网站与软件界面

- 网站页头使用 02-website/logo-header.svg，favicon 使用专用 SVG／ICO，小屏空间不足时采用独立印记。
- 180 px Apple touch 图标和 1200×630 分享图分别用于对应位置，分享图不能替代页签图标。
- 图标加载设置明确宽高或比例，保留 SVG 矢量清晰度；透明底反白文件只放在深底上。
- 产品登录页、关于页优先保持同一企业标志；产品名称和版本号作为独立界面文字，不塞进企业印记。
- 界面错误、警告、成功等功能色服务于状态识别，不能因为品牌是黑白就让状态无法区分。

### 11. App、PWA 与消息场景

- 使用完整方形背景导出 App 图标，让目标平台裁切圆角，不把展示图中的圆角烘焙进源文件。
- 现有 192/512 和 maskable PNG、manifest 配置面向网页／PWA 资产准备，不代表已经交付原生 Android 或 iOS 的全部平台资源。
- 原生 Android 后续需按官方规范交付独立前景、背景和 monochrome 资源；不能把 PWA maskable PNG 直接称为完整的 Android adaptive icon。
- iOS 等平台以当前 Apple 图标资源和模板为准，交付时复核尺寸、层次及各外观；1024 PNG 是源图之一，不等同于已经完成所有平台验收。
- App 图标只用印记，产品名显示在系统标签或界面中。后续多个产品用经过审定的产品图形或命名区分，不在同一个印记上随意加小角标。

### 12. 公司公告与办公材料

抬头使用公司全称，正文标题、编号、日期与落款采用文档实际信息。图形与公司名形成稳定首层，文化标语放页脚或次级区，不与公告标题争抢。公告模板内“标题与正文区域”等占位内容在正式发布前替换或删除。

多页文档在封面／首页完整展示，后续页可简化页眉；保留统一页边距。Logo 不作为公章、签字或批准标识使用，不能把近方形印记制作成易被误认的法定盖章图样。

### 13. 广告展板与宣传物料

按“品牌标志 → 核心内容／文化标语 → 公司名称及联系信息”的层级组织。现有 2400×900 是横版模板，不是指定任何实体展板必须采用该比例；实际尺寸变化后重新排版，不能拉伸。

远距离观看时优先减少文字并放大主信息。联系电话、网址、二维码使用真实且已确认的信息；二维码须扫码测试，留足自身静区，不让 Logo 覆盖影响识别。出血、装订、安全边距以生产商确认的成品尺寸和模板为准。

### 14. 商品与包装

按正面识别、侧面信息、吊牌等不同版位选用同一套主标。品牌标志与商品名称、规格、生产信息等分层，不能把企业标志当作商品质量认证。现有包装箱、帆布袋和吊牌效果为应用示意，不代表已有这些在售商品。

单色丝印用实色路径，烫印／压凹另交单色工艺层，刺绣等工艺先确认最细线和间隙再打样。不得从照片中的透视 Logo 抠取生产稿；不得用低清 PNG 放大印刷。

### 15. 禁止或需要另行审稿的处理

禁止非等比拉伸、旋转、镜像、闭合开放缺口、随意改圆角和笔画粗细，或把局部拆出来当新 Logo。禁止把说明图的圈线、编号、解释文字放进正式标志。

不要在不同场景另画一套“差不多”的印记。新配色、文字转曲后的字标、新产品专属图标、工艺简化版以及新的横竖组合，需作为版本变更提供对照稿，由公司确认后再纳入母版库。

### 16. 交付清单与版本管理

其他设计师交付时应同时提供：可编辑源文件、正式矢量导出、透明 PNG、应用截图、尺寸与色值说明、字体来源和版本说明。Figma／Illustrator 等源文件中的图形应保留矢量路径，文本可编辑版本和转曲版本分层保存；不能只交一张应用效果图。

建议文件名：lilin-[场景]-[组合]-[black/white]-[尺寸]-v[版本]，例如 lilin-web-horizontal-black-v1.svg。文件包版本与规范文档版本分别记录，禁止用同名文件静默覆盖已有归档。

当前 ZIP 为图形应用包 V1，本节为规范 V1.1。已确认的是设计方向和文化内容；品牌标准色、正式字体、中文字标转曲、原生 App 全平台资源以及各印刷工艺打样仍需后续落实。

### 17. 交付前检查

逐项核对名称拼写、母版形状、开放端、净空、最小文字可读性、黑白反白、透明通道、文件实际尺寸、平台裁切与导出引用。网页在浅色／深色及手机／电脑上检查；App 在实际桌面图标尺寸检查；商品与展板按实际尺寸或样张检查。占位文字、示意商品、未确认联系方式等不得直接作为发布内容。
