## 1. 品牌识别

礼林生态的业务涵盖软件与信息服务、工程配套、生态技术、设备物资及运营生活服务。品牌视觉以温和、可靠、清晰、有序为基本特征，适用于不同业务和产品。

中文品牌名统一为“礼林生态”，英文统一为“LILIN ECO”。正式公司署名使用企业全称。品牌字标、企业全称和具体产品名称分别排版，形成明确的信息层级。

企业文化表述为“善心、善念、善行”。独立视觉排版采用“善心 · 善念 · 善行”，保持词序、字号、字重和间距一致。

## 2. 标志构成与设计寓意

标志以“礼”字为基础，将汉字笔画与开放的近方形轮廓结合。左部的笔画节奏、内部转折、右下延伸端及开放缺口共同构成识别特征。

| 理念 | 对应结构 | 设计含义 |
| --- | --- | --- |
| 善心 | 中上部由笔画围合形成的白色空间 | 包容、关照与善意 |
| 善念 | 左部横画转向斜画的转折关系 | 思考、理解与连接 |
| 善行 | 右下横画的延伸与开放端 | 实践、行动与持续服务 |

上述寓意对应整体结构关系，图形以完整印记使用。结构标注中的编号、引线和说明文字仅用于规范展示。

## 3. 标准组合

| 组合形式 | 构成 | 主要应用 |
| --- | --- | --- |
| 独立印记 | 单一图形 | 页签图标、App、小头像、角标 |
| 横版组合 | 印记＋中文品牌名＋英文 | 网站页头、登录页、宣传页、包装侧面 |
| 竖版组合 | 印记在上，中文及英文在下 | 方形标签、吊牌、包装正面 |
| 企业全称组合 | 印记＋企业全称 | 公司公告、正式办公材料 |
| 文化辅助组合 | 标志＋文化标语 | 广告展板、品牌介绍、包装辅助版面 |

横版和竖版组合直接使用对应母版。空间不足时切换独立印记，产品名称在界面中作为独立文字显示。

## 4. 安全区与最小尺寸

以独立印记的可见高度为 H，安全区单位 u＝H÷5。标志外侧与其他文字、图案、裁切线及装订位置之间的距离不小于 1u。组合标志按整体外边界计算安全区，u 取其中印记高度。

文件自带透明边距计入版式空间，实际排版仍应满足安全区。App 背景延伸至图标画板边缘，核心印记保留平台裁切区域。

| 应用 | 建议起始尺寸 | 检查重点 |
| --- | --- | --- |
| 数字界面独立印记 | 可见高度 24 CSS px | 缺口、留白及转折清楚 |
| 浏览器页签 | 专用 16 / 32 / 48 px 文件 | 实际浏览器显示效果 |
| 带英文横版组合 | 完整画板显示宽度约 280 CSS px | 英文字母可读 |
| 带英文竖版组合 | 完整画板显示宽度约 220 CSS px | 中文、英文层级清楚 |
| 印刷独立印记 | 可见高度约 8 mm | 笔画与留白不粘连 |
| 印刷组合 | 横版画板宽约 60 mm；竖版画板宽约 50 mm | 最小文字实际可读 |

以上尺寸为一般应用的设计起点，最终尺寸根据载体、观看距离和生产工艺确定。刺绣、烫印、压凹、丝印及雕刻采用实物打样确认最细线和最小间隙；工艺适配稿单独编号。

## 5. 色彩与背景

### 标志用色

| 版本 | 色值 | 背景 |
| --- | --- | --- |
| 黑色 | HEX #000000；RGB 0 / 0 / 0 | 白色及明亮、平整背景 |
| 反白 | HEX #FFFFFF；RGB 255 / 255 / 255 | 深色、平整背景 |

单黑印刷以 K100 单色稿作为工艺沟通起点，最终输出根据印刷条件确定。彩色标志、CMYK 组合及专色另行制定。

### 数字界面参考色

| 色彩角色 | 当前官网色值 | 参考用途 |
| --- | --- | --- |
| 绿色 | #36593E | 主按钮、重点链接 |
| 深绿色 | #26432D | 强调及深色交互状态 |
| 暖米白 | #F8F7F3 | 页面背景 |
| 浅暖白 | #FDFCF9 | 内容背景 |
| 墨色 | #292F29 | 正文 |
| 灰绿色 | #6C7068 | 辅助文字 |
| 浅灰绿 | #DDDFD5 | 分隔线 |

上述色值为官网界面参考，不作为彩色标志定稿。产品中的警告、错误、成功等状态色按功能语义设置。

标志置于照片上时，选择明暗稳定的区域，必要时设置独立底色。正文和控件文字按实际背景检查对比度，普通文字以 4.5:1、大字以 3:1 为参考标准。

## 6. 字体与文字排版

### 字标参数

现有组合文件的字体栈为 Microsoft YaHei、Noto Sans SC、Arial。中文采用 600 字重，英文采用 400 字重。

| 组合 | 中文字号 | 英文字号 | 英文字距 |
| --- | --- | --- | --- |
| 横版 | 64 | 29 | 6 |
| 竖版 | 56 | 24 | 5 |

表内数值为对应 SVG 画板内的设计单位。整体缩放时，各项参数同比例变化。

组合文件中的文字保持可编辑，不同设备的字体回退可能改变字形与宽度。正式字标交付需锁定字体来源、版本、字重和字距，同时提供可编辑文本稿及文字转曲稿。

### 产品与办公文字

数字产品正文采用清晰的无衬线字体；品牌介绍、文化背景等版面可采用宋体或衬线标题。企业字标保持固定字形，不随产品主题字体变化。

企业全称可在完整词组之间换行。“有限责任公司”作为完整词组处理。英文品牌名保持大写拼写和规定字距。

## 7. 辅助图形与文化标语

文化标语作为次级信息，与主标保持独立层级。广告、办公及包装版面可使用完整三词组合，小尺寸图标采用独立印记。

大幅文化字可作为低透明度背景装饰。官网现有透明度约为 4.5%，用于其他载体时应按背景重新调整。装饰图形与正文、按钮、表格及关键信息保持分离。

## 8. 应用规格

### 网站与数字产品

网站页头使用横版组合；浏览器页签使用专用 favicon；Apple touch 图标为 180×180 px；分享图为 1200×630 px。小屏导航空间不足时使用独立印记。

图像组件设置明确的显示尺寸或比例。登录页、关于页和产品材料共用同一企业标志，产品名称、版本号及服务说明独立排版。

### App 与 PWA

App 图标使用完整方形背景，核心印记居中。圆角及裁切由目标平台处理，源图保留未裁切画板。

| 资源 | 当前文件 | 使用范围 |
| --- | --- | --- |
| 通用图标 | 1024 / 512 / 192 / 180 px PNG | 图标源图及应用适配 |
| PWA 图标 | 192 / 512 px PNG、manifest 配置 | 网页安装入口 |
| PWA maskable | 512 px PNG | 支持裁切的网页应用图标 |

原生 Android 图标按平台要求分别制作前景、背景及 monochrome 资源。Apple 平台按目标系统模板与外观要求输出。原生平台资源清单随具体产品项目确定。

### 公司公告与办公材料

公告抬头采用印记与企业全称，正文形成标题、编号、内容、日期及落款层级。文化标语放置于页脚或次级区域。多页材料首页使用完整标志，后续页可简化页眉。

公告模板中的占位内容在正式发布前替换。企业标志用于品牌识别，与公章、签字及审批标记分别使用。

### 广告展板

版面按品牌标志、主题内容、公司及联系信息建立层级。现有横版模板比例为 2400:900，实体尺寸变化后重新排版。

远距离展示优先保证主信息识别。二维码、网址及联系方式使用经确认的信息，二维码保留静区并完成扫码测试。出血、裁切和安装边距按生产模板设置。

### 商品与包装

包装正面、侧面及吊牌按版位选用同一套标准组合。品牌标志与商品名称、规格及其他商品信息分别排版。

生产稿使用矢量母版或满足实际输出精度的文件。烫印、压凹、丝印等工艺提供独立工艺层；刺绣和雕刻按打样结果确定适配版本。包装、吊牌及手提袋效果图用于展示版式与材质应用。

## 9. 使用限制

- 标志保持等比缩放及既定朝向，保留开放缺口和内部留白。
- 图形、字标和英文按标准组合使用，局部笔画不作为独立新标志。
- 标志不添加渐变、描边、投影、发光或照片纹理。
- 结构图的编号、引线、解释文字不进入正式标志。
- 配色、字形、工艺简化及新产品标识的变化单独建版，经确认后纳入母版库。

## 10. 文件管理与交付

### 文件目录

| 目录 | 内容 |
| --- | --- |
| 01-master | 独立印记、横版及竖版组合；SVG、透明 PNG、黑色与反白版本 |
| 02-website | 页头标志、favicon SVG / PNG / ICO、Apple touch 图标及分享图 |
| 03-app | 通用图标、PWA maskable 图标及 manifest 配置 |
| 04-announcement | 企业抬头及公告模板 |
| 05-advertising | 横版广告展板模板 |
| 06-products | 方形标签、透明单色标及吊牌 |

图形路径以 01-master 中的 SVG 为准。PNG 用于固定外观展示，应用效果图用于场景参考。

正式交付包含可编辑源文件、矢量输出、透明 PNG、应用稿、尺寸色值表及字体信息。源文件保留文本可编辑层和文字转曲层，生产适配稿单独归档。

文件命名采用“lilin-场景-组合-颜色-尺寸-v版本”，例如 lilin-web-horizontal-black-v1.svg。规范版本、图形文件版本和具体产品版本分别记录。

### 交付检查

| 类别 | 检查内容 |
| --- | --- |
| 识别一致性 | 名称拼写、路径形状、组合比例、缺口及留白 |
| 显示质量 | 最小尺寸可读性、黑白反白、透明通道、平台裁切 |
| 文件完整性 | 实际尺寸、格式、引用资源、字体及版本信息 |
| 生产适配 | 裁切、出血、工艺层、样张及实物效果 |
| 发布内容 | 占位文字、联系方式、产品信息及二维码 |

### 定稿项目

| 项目 | 后续定稿内容 |
| --- | --- |
| 彩色标志 | 标准色、CMYK 及专色 |
| 正式字标 | 字体版本、字距及文字转曲 |
| 原生 App | 各目标系统的资源、层次及外观 |
| 工艺适配 | 材质、最细线、间隙和打样版本 |
