# 礼林生态 · 软件品牌四色

企业：达州礼林生态科技有限责任公司。日期：2026年11月23日。候选编号68–71。

以67号模块互联图形为统一基础，仅调整颜色，保留合抱外轮廓、点折、圆角窗口与双端口。目标是以清楚、轻快的数字产品配色，替换此前橙色、深墨绿与麦色组合的工程材料感。四款均为配色方向，不计作四个全新构造。

## 逐款说明

### 68 湖蓝青柠

- 配色意图：湖蓝为主体、石墨为双端部、青柠用于点画与短连接，形成明快的冷色主调。
- 指引色：主体#17ADC8；辅色#304553；连接色#B5DC4D。
- 软件品牌方向：湖蓝主体、青柠信号点和石墨端部形成较明确的数字产品配色层级。
- 名称与理念：沿用67号图形来源；接纳留白、共享连接和开放端部继续表达善心、善念、善行。
- 自检：四款中较偏清爽、专业的软件品牌方向；青柠用作小面积点缀，小尺寸需控制面积，避免喧宾夺主。

### 69 晴蓝珊瑚

- 配色意图：晴蓝主体与珊瑚粉双端部相配，少量柠黄作连接，强调亲和的数字产品感。
- 指引色：主体#378ED5；辅色#F27C8B；连接色#F4CC66。
- 软件品牌方向：晴蓝与珊瑚粉形成友好的数字产品色彩对比，柠黄用于短连接。
- 名称与理念：沿用67号图形来源；接纳留白、共享连接和开放端部继续表达善心、善念、善行。
- 自检：色彩更轻快、亲和；主蓝仍较明显，但与先前蓝紫渐变不同，为清楚分区的实色方向。

### 70 绯红银灰

- 配色意图：清楚绯红作主体，冷石板色和浅银灰作辅助，减少自然材料与工程配色联想。
- 指引色：主体#E95F79；辅色#516575；连接色#B9CCD6。
- 软件品牌方向：绯红为主、冷石板色为辅，浅银灰仅承担连接，偏简洁的软件产品配色。
- 名称与理念：沿用67号图形来源；接纳留白、共享连接和开放端部继续表达善心、善念、善行。
- 自检：暖红主体清楚，色彩比原稿更活跃；银灰不代表金属材质，小面积浅色连接在极小尺寸下会减弱。

### 71 薄荷蜜桃

- 配色意图：明快薄荷与蜜桃构成主要色块，深石板色仅用于连接，保留轻快与柔和。
- 指引色：主体#29BCA0；辅色#FFA080；连接色#344C5C。
- 软件品牌方向：明快薄荷与蜜桃形成较轻松的应用品牌气质，深石板色短连接稳定视觉。
- 名称与理念：沿用67号图形来源；接纳留白、共享连接和开放端部继续表达善心、善念、善行。
- 自检：较轻快、温和，适合亲和的科技服务方向；暖冷两主色面积接近，正式品牌应用需再确定主色占比。

## 检查与使用

已查看四款原图、统一图形比较图和32、64、128像素预览，检查主要轮廓、圆角窗口与双端部是否保留，以及配色是否有清楚主次。PNG输出与原参考仍可能存在细小边缘或局部比例差异；颜色为设计指引，正式矢量母版须统一色板、填充和小尺寸规范。

软件气质属于设计评估，不代表已经通过用户行业识别测试。准确名称仍由组合字标呈现，三善理念沿用接纳留白、共同连接和开放末端。

使用内置image_gen.imagegen编辑，未使用CLI。Sharp只用于复制、外围裁边、缩放和比较排版，没有程序化替换图形内部颜色。辅助字标为系统字体位置参考，非定制字体。
