# 礼林生态 · 清透实色四案

企业：达州礼林生态科技有限责任公司。日期：2026年11月17日。候选编号55–58。

本轮针对上一批雾化感及蓝紫渐变过多进行配色调整：延续49、50、53、54的柔和轮廓，改为有主次的清楚色彩分区。柔和主要来自曲线、比例与留白；色彩不再依赖低对比的蓝紫渐变。

## 逐款说明

### 55 松绿珊瑚

- 前序轮廓：49。
- 构造：圆润礼形与分叉支撑保留，改用松绿、珊瑚与少量赭金实色。
- 配色指引：green #397563；coral #DB6B50；ochre #DBAE61。
- 工程来源：延续49的共用支撑与底部承托，属于结构来源而非直接行业图标。
- 软件来源：延续连续路径与开放连接关系。
- 名称来源：保留礼的点折开钩与分叉木形来源，未直接写出完整双木。
- 三善意图：留白接纳、共享弧线和开放末端延续善心、善念、善行。
- 中央荷花：无。
- 自检：松绿主形、珊瑚分叉与赭金连接的分区清楚，圆润轮廓延续；与49相比清晰度更强。生成PNG内部仍有少量色差，生产矢量应统一实色填充。

### 56 杏橙墨色

- 前序轮廓：50。
- 构造：舒展字形来源保留，以杏橙为主、墨绿为支撑、砖红作点画。
- 配色指引：orange #DD8B42；ink #3B473F；brick #B65C43。
- 工程来源：延续50的成对支撑和共有弧形底部。
- 软件来源：通过交汇路径体现协作来源，软件属性较间接。
- 名称来源：礼的点折与木形分叉保留，字形带有人文书写感。
- 三善意图：共用底弧与支撑体现相承，点折和开放末端延续三善意图。
- 中央荷花：无。
- 自检：杏橙为主、墨绿为辅，颜色主次明确；树形和书写感仍然较强，极小尺寸的细枝需要专版。

### 57 麦金陶红

- 前序轮廓：53。
- 构造：中央彩色荷花保留，以麦金、陶红和深橄榄实色形成清楚层次。
- 配色指引：gold #D6A837；terracotta #C96D48；olive #4B654D。
- 工程来源：延续53成对根部对花瓣的承托。
- 软件来源：共用根部与下转通路作为连接意图。
- 名称来源：左侧点折开钩可见，林为成对根部来源。
- 三善意图：莲心为善心，共用根部为善念，开放曲线为善行。
- 中央荷花：有。
- 自检：麦金中央瓣、陶红侧瓣和深橄榄根部有清楚层级；没有金属光泽意图，仍更偏生态人文气质。

### 58 莓红青碧

- 前序轮廓：54。
- 构造：中央白莲与开放带面保留，用莓红、青碧与少量暖金建立清楚分区。
- 配色指引：berry #BF5866；turquoise #3C998A；saffron #D5A64A。
- 工程来源：延续54开放带面的共有支撑关系。
- 软件来源：开放通道与图标式紧凑轮廓。
- 名称来源：点与开钩保留礼的来源，林为抽象支撑，不能当作可读完整合字。
- 三善意图：中央留白、带面共接与向外开放继续联系三善。
- 中央荷花：有。
- 自检：莓红与青碧形成明确冷暖主次，中央白莲清楚；颜色鲜明但轮廓仍柔和，个别尖端可在选定后再作光学校正。

## 检查与制作说明

已查看四款原稿、比较图及32、64、128像素预览。重点核对色彩分区是否清楚、蓝紫雾化是否退出，以及圆润形状和中央荷花是否延续。57、58保留中央荷花，55、56侧重名称笔势。四款为前序造型的配色方向，不将它们计作四种全新构造。

颜色为设计指引。生成PNG仍存在少量内部像素色差及边缘抗锯齿，不属于已经统一色板的印刷母版。选定后应按指引制作矢量平涂、单色和小尺寸版本。工程、软件及三善对应为创作意图，并非未经说明的识别测试结论。
