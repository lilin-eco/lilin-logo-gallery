# 字形来源说明

规范繁体名称写作「禮林」，其中「林」繁简同形。

教育部《異體字字典》A02906-002 收录「礼」为「禮」的古异体，并列举古籍用例。古异体的存在不能据此把「礼」称为现代规范繁体「禮」。

- https://dict.variants.moe.edu.tw/dictView.jsp?ID=31003&la=0
- https://dict.revised.moe.edu.tw/dictView.jsp?ID=62077&la=0&powerMode=0

本轮主线以「禮」的礻、豊构造作为来源，与「林」的双木重构为艺术合文。合文是商标图形设计，不是新造的规范汉字。古异体路线独立标注，不用字源解释掩盖图形识别问题。
