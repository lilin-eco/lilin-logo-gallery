# 礼林生态｜中国红拼音组合

企业：达州礼林生态科技有限责任公司。日期：2026年11月26日。图形来源：重点候选91圆方共融。

![中国红拼音组合](lilin-shengtai-red.png)

## 组合规格

图标保留用户提供的蓝紫青原图，位置与像素不变；下方居中放置礼林生态的拼音LILIN SHENGTAI。拼音采用Segoe UI Bold，字体轮廓已转路径，字距参数18，选用中国红色值#D71920。画布1254×1420像素，文字宽约841像素、高约70像素，顶部位于1220像素。

不增加中文行或其他标语。已逐字检查拼音，并核对图形所在区域的像素与输入完全一致。
