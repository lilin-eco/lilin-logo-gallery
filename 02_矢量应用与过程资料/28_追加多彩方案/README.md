# 礼林：新增五套多色方案

日期：2026-11-16。公司：达州礼林生态科技有限责任公司。

沿用上一轮莲形主标，继续比较颜色的明度、冷暖关系及分瓣渐变。新增方案使用D–H编号，避免与上一轮A–C混淆。对比图右下角的“上轮B”仅作参照，不计入新稿。

## 配色方向

| 编号 | 名称 | 目标色值 | 设计取向 |
| --- | --- | --- | --- |
| D | 青柠海蓝 | 左/点画 #24427B；右 #009FAF；上 #A1BB3F | 深蓝稳定，海蓝清爽，青柠突出向上生长感 |
| E | 玫紫晴蓝 | 左/点画 #4947AF；右 #368BCD；上 #EB6E8D | 温暖玫色与冷蓝紫平衡，亲和而明快 |
| F | 橘红海蓝 | 左/点画 #E66A47；右 #316FA7；上 #FF9E3D | 两组暖色带来活力，海蓝提供冷暖平衡 |
| G | 日光渐彩 | 上 #F2C14E → #F07842；左/点画 #8750B8 → #E5709C；右 #2E72BA → #27BDBA | 每瓣独立渐变，色相最丰富，适合比较更鲜明的数字视觉方向 |
| H | 雾蓝杏紫 | 左/点画 #527BA8；右 #9B84B7；上 #E5A36D | 中等明度的柔和配色，气质更安静温润 |

表中色值为配色目标。栅格效果稿存在渲染色阶，选定后应在矢量母版中明确标准色及渐变参数。

## 图形与理念

三善仍由开敞花心、相承转折及向外打开的通道表达，颜色强化三个部分的节奏，不新增文化小图标。图形主要借用原“礼”印记的手势与莲瓣构造；完整公司名称通过辅助字标读出，不宣称主图已经逐字保留完整礼林二字。

组合图的“礼林生态”和LILIN ECO为系统无衬线字体排版参考，主图仍是本轮比较重点。

## 自检

五张原图已逐一查看，并检查了统一对比及256、128、64、32px预览。主轮廓、点画、白色转折和开口保留；换色前后经紧致边界归一的轮廓交并比约98.23%–99.55%。该指标仅描述图像轮廓接近程度，不代表受众识读或记忆测试。

D的青柠、G的浅黄与H的柔和色在32px及浅底小图标中会更轻，正式应用需单独校正色深和基部细缝。当前为PNG配色候选，尚未制作纯路径生产母版，也未替换官网。
