## 组合原则

图标保持原有蓝紫青配色和造形，使用同一份图像裁边、等比缩放后置于相同坐标，不用图像模型重画。10款均在图标下方居中放置简体“礼林”二字，不添加英文或理念标语。理念由图形的中心留白、相互承接与右侧开放继续表达。

画布1000×1080像素。图标600×675像素，顶部65像素。文字顶部835像素，常规高度约140像素；根据宽扁或紧凑方向适度调整比例。文字以深蓝为主，T08使用蓝至青的克制渐变。

## 评估

T01较均衡，可优先比较。T03字面宽扁、笔画厚重，科技气质更强。T06偏人文雅致。T08前倾约8度，动势更强。T02圆润亲和，但笔画偏轻；T04与T10较细，组合缩小后文字更弱。T05紧凑有力，但字间较近。

已检查两组放大图、总览及160像素宽组合预览。礼与林的字形完整，均位于图标下方，图形一致。T08已校正前倾后的光学居中。

## 交付与复现

每款包含PNG、固定字形SVG及缩小预览。SVG中的中文已转路径，无需观看者安装字体；图标仍是嵌入的原PNG，不将它标注为全矢量母版。所用字体是实际字体的排版研究，非十套全新原创字体。字体选定后再核实最终商用授权与应用规格；本档案不分发字体文件。

制作使用System.Drawing导出字形轮廓、SVG排版和sharp栅格化，没有调用图像生成模型。参数详见typography-specs.json，字形路径详见glyph-outlines.json；完整复现需安装相同字体。build-font10.mjs与font-outlines.ps1保留当前工作区的构建路径。
