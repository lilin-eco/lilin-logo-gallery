# 礼林：图形主标多色方案

日期：2026-11-16。公司：达州礼林生态科技有限责任公司。

以本轮“留白莲形”图形为基础，比较同一构造的三套多色处理。颜色直接进入主标的花瓣和笔画，不依靠背景或辅助文字制造多色效果。当前用于选择配色方向，尚未替换官网，也不代表图形已最终选定。

## 三套方案

| 方案 | 颜色处理 | 目标色值 | 设计取向 |
| --- | --- | --- | --- |
| A 蓝青暖橙 | 三瓣分色，左蓝、右青、上橙，小点画沿用蓝色 | 蓝 #2663AA；青 #24B6A8；橙 #F28856 | 冷暖对比清楚，兼顾专业感与温度 |
| B 蓝紫青渐变 | 每个花瓣采用克制的独立渐变，保留三组色相 | 上部紫 #7354D8 → 靛蓝 #475BE6；左侧蓝 #345EDA → 青 #40BDD8；右侧青绿 #1EA999 → 水青 #34C7C2 | 更偏数字产品与现代软件品牌气质 |
| C 珊瑚紫暖金 | 三瓣分色，左紫、右暖金、上珊瑚，小点画沿用紫色 | 紫 #7760B2；暖金 #DCA842；珊瑚 #E76B64 | 温暖、丰富，强调人文与多业务的包容感 |

上述色值是本轮的配色目标，栅格构思图存在渲染色阶；正式矢量定稿时应重新明确纯色、渐变端点与色彩输出规格，不能将每个像素都视为精确标准色。

## 理念与识别

善心通过花心的包容空间表达；善念通过原印记转折及花瓣相承表达；善行通过向外延伸的通道表达。多色在此基础上强化三部分相承的节奏：A以暖橙传递温度、蓝色传递思考、青色传递行动与生长；B强调相互过渡；C强调温暖与包容。这些是设计意图，不把某种颜色解释为文化理念的固定或唯一含义。

图形中的主要字形线索来自原“礼”印记，林的双干只保留为抽象构造参考，未声称完整读出礼林二字。组合展示用简洁的“礼林生态”辅助字标明确公司名称。辅助字标是系统无衬线字体排版参考，不是本轮绘制的定制字库。

## 自检

- 已逐张查看三幅生成原图，白色转折通道、小点画、基部与开放端均保留。
- 与单色源图按紧致边界归一后比较前景轮廓，A/B/C交并比分别约99.05%、98.59%、99.20%。这是换色过程的轮廓对照，不是受众识读、好感或记忆测试。
- 已查看256、128、64、32px预览。大体轮廓仍可观察；32px时基部细缝和较浅的青色、暖色区域会弱化，正式小图标需单独校正。
- A与C以分色为主，B以分瓣渐变为主；渐变版仍需保留可用于单色场景的独立版本，当前文件没有冒充已完成的整套生产母版。
