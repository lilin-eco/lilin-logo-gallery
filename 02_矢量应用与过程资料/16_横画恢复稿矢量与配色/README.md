# 禮林生态合字 Logo 候选

公司：达州礼林生态科技有限责任公司。

本目录提供经过筛选和尺寸检查的一个候选，不包含淘汰稿。状态与检查依据见 `SELF-CHECK.md`。

## 查看

- `preview-symbol.png`：单独图标，米白背景。
- `preview-lockup.png`：与公司名称、英文和理念的组合参考。
- `qa-sizes-and-colors.png`：实际尺寸及三种配色检查表。

## 可编辑与透明素材

- `symbol-green.svg`：当前绿色矢量母版，色值 #36593E。
- `symbol-black.svg`：当前黑色矢量母版。
- `symbol-white.svg`：当前白色矢量母版。
- `symbol-{green|black|white}-{2048|512|256|128|64|32}.png`：对应透明底 PNG。

三个 symbol SVG 均为原生路径，不依赖字体、外链或嵌入位图。透明素材没有背景；展示图背景为 #F8F7F3。

`preview-lockup` 中的中文组合名称使用 Microsoft JhengHei 系统字体，英文使用系统无衬线字体。它是排版参考，不是另行设计的字标；不提供该字体文件。

## 制作与检查留档

- 初稿使用内置图像生成工具完成；`generation-prompt.json` 留存对应提示词。
- `generation-original.png` 是生成原稿，仅作来源参考。
- `source-traced.svg` 是光学校正前的描摹参考，不能替代当前 `symbol-*.svg` 母版。
- `trace-check.json` 记录光学校正前的描摹对照指标。
- `optical-adjustment.json` 记录 64px 粘连的局部修复。
- `size-check.json` 记录最终尺寸与配色验证。

本目录不包含网站部署修改。
