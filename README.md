# 礼林 Logo 统一设计档案

在线图册：https://lilin-eco.github.io/lilin-logo-gallery/  
组织仓库：https://github.com/lilin-eco/lilin-logo-gallery

仓库与图册公开可见。勾选仅用于各自浏览器内的方案比较；讨论时使用图册编号。网站从main分支根目录发布，更新资料后运行`node scripts/build-pages.mjs`刷新首页和目录导航，再提交并推送。

企业：达州礼林生态科技有限责任公司。更新日期：2026年11月16日。

## 统一选择入口

双击 [打开预览.html](打开预览.html)。所有阶段集中展示，新增20款候选按本轮21–40排列在最前面。可按阶段或名称筛选，勾选“加入比较”后点击“只看已选”并排查看。浏览器允许本地存储时会保留已选编号。已打开旧预览时刷新页面即可。

## 目录与统计

- 01_生成原稿：001–134连续编号，附原图、说明和版本信息。
- 02_矢量应用与过程资料：31组，含所有后续设计资料。
- 全部设计说明.md：逐稿造型、理念与自检。
- 文件清单.csv / 文件清单.json：归档路径及SHA-256。

共134张生成原图、20个阶段、31组资料、67份SVG。本次新增20个供选方向和3张修正前稿。候选对应115–134，修正前稿112–114。原先111张全部保留，历史编号不变。展示板里的多个图形、缩小版、裁边版和配色导出不重复计作原图。

## 使用说明

设计资料统一保存在此档案，后续继续追加。原图保持原始字节；PNG概念稿不等于矢量生产母版。艺术合字与系统字体研究不自动视为规范字形或定制字标。理念记录属于创作意图，未进行盲测识别或商标近似检索。历史提示中的旧路径保留作来源记录，实际文件以当前档案为准，旧构建脚本可能依赖旧路径。

只包含Logo及相关设计资料，不包含登录信息、密钥、邮箱内容或完整会话日志。26张非Logo官网或场景图仍不纳入。
