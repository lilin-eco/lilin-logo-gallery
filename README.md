## 收录

- 01_生成原稿：001–194连续编号，附原图、说明和版本信息。
- 02_矢量应用与过程资料：40组。
- 全部设计说明.md：逐稿设计判断。
- 文件清单.csv / 文件清单.json：路径及SHA-256。

共194张原图、28个阶段、40组资料。本轮20个候选对应175–194，另保留0张修改前稿。此前所有编号保持不变。板内多个图形、裁边和缩小导出不重复计作生成原图。

## 使用与发布

原图保持原字节。PNG为概念稿，艺术结构不等于规范汉字，系统字体不等于定制字标；未进行盲测识别或商标近似检索。历史提示中的旧路径为来源记录，实际文件以本档案为准。

仓库与图册公开可见。网站由.github/workflows/pages.yml发布main分支根目录。更新资料后运行node scripts/build-pages.mjs，再提交并推送。历史构建脚本可能依赖旧路径。

只收录Logo及相关资料，不包含登录信息、密钥、邮箱内容或完整会话日志。26张非Logo官网或场景图不纳入。
